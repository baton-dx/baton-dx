## Codebase Patterns
- Zod schemas go in dedicated files, types derived via `z.infer<typeof schema>`
- Tests co-located: `foo.ts` → `foo.test.ts` in same directory
- Use `safeParse()` in tests to check both success and failure cases
- Biome formatting: short imports fit on one line, don't break across multiple lines
- Schema pattern: define schema → export type → use `.default()` for optional fields with defaults
- YAML I/O pattern: see `loadGlobalConfig` / `saveGlobalConfig` in `core/src/config/global-config.ts`
- Global config has `ai.tools` and `ide.platforms` arrays — project preferences mirror this structure with added `useGlobal` boolean
- CRITICAL: Run `bun run build` before `bun run typecheck` when adding new core exports — CLI resolves core from `dist/` not source
- Biome enforces alphabetical import sorting — insert new imports in correct alphabetical position
- Two gitignore mechanisms: `init` adds `.baton/` with `# Baton cache`; `sync` uses `updateGitignore()` with `# Baton managed` section. Don't mix them.
