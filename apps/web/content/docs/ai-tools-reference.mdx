## Detection

Baton detects installed tools by checking for:

1. **CLI binary** in `PATH` (e.g., `claude`, `cursor`, `code`)
2. **Config directory** existence (e.g., `~/.claude/`, `~/.cursor/`)

```bash
baton ai-tools scan
```

## Config Types

| Type | Description |
|------|-------------|
| `skills` | Skill directories with `SKILL.md` |
| `rules` | Markdown rule files |
| `agents` | Agent files with YAML frontmatter |
| `memory` | Context memory files |
| `commands` | Slash command files |

Each config type has both **project** scope (project directory) and **global** scope (home directory).

## Tool-Specific Behavior

### Claude Code

- **Memory file:** `CLAUDE.md` (project root or `~/.claude/CLAUDE.md`)
- **Rules:** Standard Markdown, placed in `.claude/rules/`
- **Skills:** Directory-based with `SKILL.md`, placed in `.claude/skills/`
- **Commands:** Placed in `.claude/commands/`

### Cursor

- **Memory file:** `AGENTS.md` (project root)
- **Rules:** Transformed to `.mdc` format with `description`, `globs`, and `alwaysApply` frontmatter
- **Legacy paths:** `.cursorrules` (single rules file, deprecated)

### GitHub Copilot

- **Memory file:** `.github/copilot-instructions.md`
- **Rules:** Placed in `.github/instructions/` with `.instructions.md` extension

### Windsurf

- **Memory file:** `AGENTS.md` (project root)
- **Rules:** Placed in `.windsurf/rules/` as standard Markdown (no frontmatter)

## Targeting Tools

Limit which tools Baton configures in your `baton.yaml`:

```yaml
ai:
  targets: [claude-code, cursor]
```

Or in a profile manifest:

```yaml
ai:
  tools: [claude-code, cursor, windsurf]
```
