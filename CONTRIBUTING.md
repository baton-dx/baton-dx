# Contributing to Baton

Thank you for your interest in contributing! Please see the full [Contributing Guide](docs/11-contributing.md) for:

- Development setup
- Coding conventions
- Testing guidelines
- Commit conventions
- PR workflow

## Quick Start

```bash
git clone https://github.com/baton-dx/baton-dx.git
cd baton-dx
bun install
bun run build
bun run test
```

## AI-Assisted Contributions

We actively encourage the use of AI tools (such as Claude Code, Cursor, GitHub Copilot, etc.) when contributing to this project. AI-assisted development is a core part of how Baton is built.

That said, **human review and testing of all code is non-negotiable**. Every pull request must be reviewed, tested, and understood by a human contributor. We do not accept PRs from fully autonomous bots (e.g., OpenClaw). If you use AI tools, make sure you understand and verify the code before submitting.
