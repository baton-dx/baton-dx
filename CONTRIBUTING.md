# Contributing to Baton

Thank you for your interest in contributing! Please see the full [Contributing Guide](docs/11-contributing.md) for:

- Development setup
- Coding conventions
- Testing guidelines
- Commit conventions
- PR workflow

## Quick Start

```bash
git clone https://github.com/baton-dx/baton-dx.git
cd baton-dx
bun install
bun run build
bun run test
```
